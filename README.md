# Reflector Tailwind CSS
A simple PHP-based tool for Tailwind CSS.

## Requirements
- PHP 8.0 or higher
- Terminal or Command Prompt

## Installation
### 1. Clone the Repository
```bash
git clone https://github.com/ariprw/reflector-tailwind
```

### 2. Navigate to the Project Directory
```bash
cd reflector-tailwind
```

### 3. Run the Script
```bash
php reflector.php
```

The script runs in the terminal and performs the operations implemented in reflector.php.
